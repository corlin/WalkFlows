# 参考反投影与标定版本契约

2026-11-07。本轮取得固定仓库完整索引：2879 项，truncated=false。site02 没有独立 camera-positioning-annotations 文件；该目录现有资源属于 site01/site04，不能移用来证明 site02 精度。

## 版本不能混用

site02_scene01_v1 引用 C0001001_v10、C0001011_v10，与当前短片 manifest 一致。v2 引用 C0001011_v4；v3 引用 C0001001_v8、C0001011_v4，第一台 scale=1.82；v4 引用 C0001001_v6、C0001011_v9。因此数字更大的场景版本不是当前相机资源的可直接替换升级，不进行替换。

取得的 scene-info_tc.cpp 只检查场景 JSON 读写回环，不验证物理标定。json-io.cpp 与 distortion-model_tc.cpp 本轮仍未下载成功，不声称已经运行完整原生相机测试。

## 可执行参考反投影

scripts/probe_site02_reference_overlay.py 将既有参考地面轨迹经场景旋转逆变换到相机射线，再用有边界的数值最小二乘反解多项式畸变。数值逆不是上游畸变缓存实现；它只作为研究对照。每台相机全部 218 点求解成功、位于镜头有效域，且用已编译上游 lift 重新正向核验，最大归一化残差约 2.0e-12 / 9.6e-13。该残差验证逆解自洽，不是物理精度。

在最长范围内局部轨迹与参考路径相对应的暂定假设下，第一路 212 个可比较帧，参考投影减框底点的中位偏移为 x=-0.43px、y=-23.09px；第二路 144 帧为 x=17.11px、y=37.85px。不能把该对应假设当成正式身份标注，也不能拟合一个固定偏移后声称精度改善。

0/60/120/180 帧反投影图显示：第二路参考地面点落在被柜台遮挡的图像区域，而检测框底停在可见人体下缘；第一路参考点更接近人物脚部附近，但仍不等同于框底中心。这提供了遮挡脚点偏差的定性证据，不排除参考定义、同步和残余标定误差。没有新增人工点位或视频标注。

输出在 data/processed/site02-reference-overlay：参考像素 CSV、带明确 REFERENCE 标签的对照图与 summary.json。它们不是自动估计的顾客轨迹。

取舍：不换错标定版本，不用参考去拟合视频脚点修正，不将数值回环误差当成定位精度。优先保留视角不确定性，并验证上游对不确定观测的实际行为，见 23 文档。

## 遮挡偏移分布复核

在参考路径与各相机最长局部轨迹对应的假设下，第一路212个可比较帧的参考投影减框底纵向差中位数为-23.09像素，只有7帧为正；第二路144帧全部为正，中位数37.85像素，10%–90%分位为23.57–40.18像素。图像y轴向下；第二路持续正偏与柜台遮挡观察一致，但不证明参考身份对应或标定准确，不能直接用固定偏移修正。

## 固定数据集与上游姿态接口复核

已读取 Hugging Face 固定版本 6cf0e1066653f7efe1d0aae5c49860b19ef9a6e5 的 site02 样例目录，只有两路视频、manifest、ground-truth、hash 和 expected-output，没有单独姿态缓存；该结论仅覆盖此目录。目录快照保存在 data/upstream-research/site02-hf-tree.json。

取得 multiview 固定提交的 pose-3d.hpp。该接口使用2D骨架并包含身高候选范围、概率和视差权重，说明其姿态定位涉及额外模型与假设，不能把单个2D脚踝预测直接视为已验证的地面位置。本轮仅核查头文件，未运行3D姿态定位，也不能据此评价其准确率。

取舍：不把额外姿态模型输出直接升级为脚点真值；如继续比较，必须单独记录权重来源、遮挡置信度与已有参考的覆盖限制，并保留质量门禁。
