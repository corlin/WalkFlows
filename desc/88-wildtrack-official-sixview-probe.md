# WILDTRACK 官方数据的六镜首帧检测诊断

2026-11-13。上轮 site04 046 的姿态模型对照和几何反投影补充见 [site04 046 记录](87-site04-046-diagnostic.md)。为获取逐镜框参考，本轮检查 [WILDTRACK 官方数据页面](https://www.epfl.ch/labs/cvlab/data/data-wildtrack/)：七个真实户外相机、标定与位置标注；官方说明标注为 400 帧、2 fps，而原视频及提取图像另有不同帧率。该数据是户外行人，不能代替室内零售场景验证；使用和再分发许可在本次检查中仍未确认。

此前本机访问超时；本轮 WSL 直连与本机代理访问官方 ZIP 的 HEAD 均返回 200。官方归档约 6.81 GB，ETag 为 `"5b86d551-195c226a6"`，支持 Range。为避免完整下载，仅读取 ZIP 目录并提取 00000000 时刻 C1–C6 图像及同帧 JSON；每项核对归档本地文件名、长度及 CRC，记录 SHA-256 至本机 `data/processed/wildtrack-official-frame0/manifest.json`。归档的部分条目存在 4 GiB 偏移差异，提取时逐项核对候选文件头而不是假定统一偏移；归档 CRC 和服务器 ETag 不是独立发布的整包 SHA-256，不能据此声称完整归档的密码学校验。数据不提交仓库。

使用项目现有 YOLO11n 权重、640 输入、0.25 置信度、GPU，逐镜匹配有效标注框，IoU ≥ 0.5 的一对一最大匹配；按相机计数，同一人可在不同镜头重复。先做一次模型预热，正式六次推理均未记录到警告；首次未预热尝试曾有 NMS 超时警告，因此不以其作为主要证据。

复现（需先准备上述本机提取文件及清单）：

```bash
.venv/bin/python -m scripts.probe_wildtrack_official --directory data/processed/wildtrack-official-frame0 --weights data/models/yolo11n.pt --device 0 --output /path/to/new-report.json
```
