# WILDTRACK 六视角单帧邻近关联条件对照

2026-11-13。针对 [五时刻六镜检测检查](88-wildtrack-official-sixview-probe.md) 的固定样本，进一步检查结果页相机对邻近候选的行为。WILDTRACK 是户外数据；样本虽来自官方归档，但再分发和使用许可仍未确认。原图、标注及六相机的内外参按官方 ZIP 的文件头、长度、CRC 和本地 SHA-256 校验；服务器 ETag 和 CRC 不是独立发布的整包 SHA-256。

遵循 [MVDet 数据读取器](https://github.com/hou-yz/MVDet/blob/master/multiview_detector/datasets/Wildtrack.py) 的相机文件顺序及厘米单位，使用每视角的无畸变内参和外参将检测框底部中心投影到地面，换算为米；没有使用额外地面 ROI。分别对每个时刻、每对相机，按结果页相同的 0.5 米距离门限和双向唯一规则生成候选；存在竞争的边单独计数。检测使用同一 YOLO11n、640、0.25，参考框以 IoU ≥ 0.5 进行一对一分配；若候选任一端未匹配参考框，分类为未知。候选仅是单帧未跟踪检测的空间邻近；其 ID 是临时检测序号，不是 ByteTrack 或真实身份。

合计按相机对和时刻重复，同一人可出现在多个相机对，不是人员数。最后一列仅计算同一参考编号在两镜均有 IoU 匹配且可投影的检测，不含漏检、无标注及不可见目标；它是条件性覆盖分母，不是完整召回。相同 / 不同参考编号分别只意味着与该标注编号一致 / 不一致；未知候选不能自动视作正确或错误。相机同步、标定、检测框、脚点和阈值误差都会改变结果。参考框与地面参考来自共享标注模型，不能用此证明物理定位或身份真值。
