# 研究布局配置实施计划

依据 `01-product.md`、`02-architecture.md` 与 `29-local-review.md`。保留现有仅浏览器内的区域交互，升级为多项布局：每项具有稳定 ID、名称、类型（区域/点位）及矩形边界，配置具有场景标识、布局版本和格式版本。先支持 JSON 导出导入，便于跨浏览器复现；矩形只是 MVP 能力，不能声称覆盖任意多边形。参考路径事件仍仅为几何候选。

1. 测试配置格式、场景边界、唯一 ID、非法数字及导入校验；拒绝无效配置，不能部分应用。
2. 实现配置验证和安全修改，任何修改递增布局版本；跨场景导入拒绝。
3. 接入现有页面：列表选择、增改删、导入导出，且保留旧版单区域数据的迁移；变更只发生在用户操作时。
4. 使用真实样本及浏览器测试迁移、存取、导出导入和事件跳帧，更新状态文档。正式定位、去重及业务事件仍需另外完成。
