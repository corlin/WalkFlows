# site03 association reference-proxy diagnostic

The research hypotheses are built without using reference IDs. This diagnostic compares each source observation with same-frame reference points at radii 0.25, 0.5 and 1.0 scene units. An assignment is retained only if the observation has exactly one reference within the radius and no other observation in the same camera and frame can claim that reference. All observations, including ones with multiple nearby references, compete for references. Cameras are evaluated separately. Missing reference frames, no candidate, multiple reference candidates and competing observations remain explicit, not negative labels.

For each hypothesis, the output includes reference-proxy support by member, plus every frame in which multiple hypotheses independently point to the same reference. This identifies possible over-fragmentation for review, but is not an identity metric: reference visibility and annotation completeness are not established, and both the association and the comparison use experimental floor positions. Several observations in one hypothesis and frame can describe one person; counts are source observations, not people or independent events. Unmatched data cannot be interpreted as false positives or missed people.

On the existing fixed sample, the 549 source observations yield 460, 541, and 541 unique proximity assignments at radii 0.25, 0.5, and 1.0 respectively. The same reference points have multiple hypothesis candidates in 6, 20 and 24 reference-frame pairs at those radii. At radius 1.0, eight observations are ambiguous; at 0.5, eight have no candidate. This threshold sensitivity and the absence of independent identity truth rule out interpreting these figures as accuracy or as a basis for automatic merging. Inspect `data/processed/site03-association-diagnostic/summary.json` for all candidate frames and per-camera supports. Inputs are recorded with SHA-256 hashes.

Reproduce with `.venv/bin/python scripts/diagnose_site03_associations.py` after rebuilding the hypotheses, or run the full research verifier. No new data labels or model training are used. The next necessary work is to inspect fragmentation causes against video and independent evidence, and improve the association while retaining uncertainty and evaluating on separate evidence.
