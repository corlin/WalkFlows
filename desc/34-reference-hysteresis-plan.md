# 参考路径区域滞回计划

目标是让研究回放中的矩形区域候选具备可解释的时间和距离过滤，服务 W07，而不将参考路径或未验证坐标变成真实顾客事件。保持原始几何事件接口供对照。

- 为选中矩形设置明确的边界距离、连续确认时间和最大帧间隔；边界带标记为不确定，不提供精确的进出时间。
- 初始或缺口后的区域状态必须连续确认；已处于区域内时不补造进入事件。跨缺口不拼接、不输出转移；边界带或相反观测会中止待确认候选。
- 输出确认时间、候选证据起始帧及上一稳定状态最后观测时间；证据范围不是实际穿越时间的严格置信区间。
- 使用人工构造的抖动、缺口、时间阈值和边界场景测试，再用真实参考轨迹和浏览器交互验证；在页面突出研究参数和数据限制。
