# 多区域参考候选时间线

2026-11-08：本地回放将所有已配置矩形区域及点位的参考路径候选，按确认帧组织为时间线。每项使用同一组边界缓冲、连续确认和最大帧间隔；同一帧的多个候选并列，不人为排列成先后顺序；不同项目产生的同一缺口只显示一次。点击可跳转确认帧。无候选不是无人或无访问。

`walkflows/local_zones.js` 的 `referenceRoute` 保留候选所属项目、类型、候选种类及证据起始帧。数据来自上游参考路径而非本项目验证的客户身份或实际平面坐标；区域可能重叠、候选可能受阈值影响，不应解释为经过人数或确定区域转移。参见 [滞回说明](35-reference-hysteresis.md)。

Node 测试覆盖同帧重叠、多项目缺口去重、缺口后的状态、空配置和重复 ID；Edge 无头浏览器使用实际参考路径检查多项并列、跳帧和阈值变化。真实跨镜身份、正式旅程及区域漏斗仍未完成。
