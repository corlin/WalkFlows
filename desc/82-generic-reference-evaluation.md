# 通用处理与参考轨迹的条件性对照

2026-11-13。针对已用于开发的 site03 006 和 007 两组录像，比较通用 YOLO11n + ByteTrack 的两种输入：完整 1792×672 左右拼接画面，和只分析 sensor0 左侧 896×672 画面。权重、置信度 0.25、处理设备、左侧近似平面映射和 0.5 场景单位邻近阈值相同；裁剪改变了检测尺度和跟踪输出，不能认为是相同检测样本上的配对实验。两组同属已探索场地，不能作为独立场景或保留测试集。

相机配置支持可选 `analysis_roi: [x,y,width,height]`，要求整数且位于原视频范围内。检测使用该区域，保存的检测框和脚点转换回原始视频坐标；平面映射和有效多边形也使用原图坐标。site03 转换脚本为拼接样本设置左侧 ROI，这不应照搬到普通独立相机视频。

| 录像 | 输入 | 有效投影观察 | 有参考且有唯一局部 ID 的投影观察 | 阈值内一对一邻近 |
|---|---|---:|---:|---:|
| 006 | 完整拼接画面 | 813 | 780 | 339 |
| 006 | 左侧 ROI | 739 | 723 | 543 |
| 007 | 完整拼接画面 | 1279 | 1215 | 466 |
| 007 | 左侧 ROI | 851 | 754 | 504 |

计数按相机和帧相加，同一人跨镜及连续帧会重复出现。匹配结果受 0.5 阈值截断；未匹配参考不能当作漏检，因为相机可见性、参考完整性和同步未独立证明。006 的 C0001025 与 C0001053 两路在两种输入下均没有有效投影；007 裁剪后 C0001029 的邻近数从 80 降至 22，C0001053 从 96 降至 22。虽然汇总邻近数量增加，覆盖下降且不同镜头结果不一致，不构成全面改进或模型精度提升的证明。

参考轨迹需事先确认与视频帧零点、帧率和场景坐标对应。命令 `project-evaluate-reference --output RUN --reference ground-truth.json --distance 0.5 --assume-aligned --report NEW.json` 会检查零偏移、帧周期、视频与观察哈希，逐镜输出投影数量、参考邻近匹配数、条件距离及来源哈希；这些检查不证明实际同步。006 参考仅覆盖 399 帧而视频有 400 帧；007 参考有 500 帧和 2 条轨迹。报告路径分别为本地忽略目录 `data/processed/site03-generic-plane/generic-reference-report.json`、`site03-006-roi-v1/report.json`、`site03-007-generic-plane/generic-reference-report.json` 和 `site03-007-roi-v1/report.json`。

后续应在不同场地和可证实可见性的数据上固定评估方案，分别检查检测、局部跟踪、平面位置与跨镜候选；继续分析无投影镜头、裁剪引起的覆盖损失和脚点偏差。不能根据这些邻近数量宣称真实身份、人数或区域事件正确。
