# Scene-wide reference coverage diagnostic

The diagnostic compares final pose-based research hypothesis positions to all published site03 floor-reference points at each frame, using maximum-cardinality one-to-one spatial matching and three exploratory radii. This is a scene-wide comparison, unlike the existing separate camera-local comparison. It records matched IDs and distances, unmatched IDs and unresolved spatial conflicts per frame. The reference is unavailable at video frame 399; that frame is excluded rather than treated as empty. Sources are hash checked and recorded.

At radii 0.25 / 0.5 / 1.0 scene units, respectively, the fixed sample has 297 / 353 / 357 matched position pairs; 84 / 28 / 24 unmatched valid prediction positions; and 753 / 697 / 693 unmatched reference positions. One hypothesis-frame is an unresolved spatial conflict. At radius 0.5, reference IDs 0 and 1 have 326 and 27 matches respectively; IDs 2 and 12 have none, although their paths contain 295 and one reference points. At frames 109 and 111?117, no valid model point matched any reference at this radius. These are correlated position samples, not independent people.

The reference does not establish camera visibility or annotation completeness, projections and alignment remain experimental, and the thresholds are not calibrated. Unmatched reference points are not proven detector misses; unmatched model points are not proven false positives. These counts are not precision, recall, ID accuracy or customer counts. They identify priority intervals and paths for investigation without using reference identity to build model tracks.

Run `.venv/bin/python scripts/evaluate_site03_scene_coverage.py` after the usual pipeline, or run the full research verifier. The ignored `data/processed/site03-scene-reference-coverage/report.json` contains every frame, matching distance, source hashes and the limitations. Tests cover one-to-one competition, conflict handling, missing reference coverage and malformed duplicate samples.
