# One-click reference flow example

The site03 layout form offers ?generate reference flow example? when the current layout is empty. It creates two explicitly named example rectangles with a gap, selects the published-reference analysis source and preserves the selected analysis window. It refuses to overwrite an existing layout. The rectangles are for exercising the research workflow and are not real store zones.

With the fixed clip and full frame window, the page shows one north-to-south reference transition candidate, model comparison zero, and exclusion of the last frame because reference coverage ends earlier. Selecting the candidate seeks to frame 114. This illustrates a traceable existing-reference analysis, not model accuracy or verified customer traffic.

A browser run checked generation, the model/reference side-by-side display and the seek to frame 114. The temporary example zones were removed after testing. Unit tests check nonoverlap, coordinates, layout validation and actual fixed-sample comparison. The regular verifier runs these checks.
