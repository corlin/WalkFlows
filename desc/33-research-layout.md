# 研究布局配置

2026-11-08：本地回放支持多个矩形区域与点位；每项有稳定 ID、名称、类型及边界。布局 JSON 包含格式版本、场景 ID、本地修订号和项目列表；增改删递增修订号。修订号不保证跨设备全局唯一，不是完整审计历史。导入会替换浏览器内当前布局并恢复文件中的修订号，因此导入前可先导出备份。

构建回放：`.venv/bin/python scripts/build_local_review.py`。启动方式见 [本地回放说明](29-local-review.md)。布局仅保存在访问页面的浏览器 localStorage；导出 JSON 可用于备份或迁移。导入前整体检查场景、格式、唯一 ID、类型、数量、坐标边界及有限数值；失败时不修改已保存布局。旧版浏览器单区域可读取并在下次保存时迁移，旧存储项不会主动删除。布局仅适用于 site02-v1；矩形点位表示空间范围，不表示业务咨询或成交。

页面显示选中项目的参考路径几何候选，候选已加入可调整的时间/距离滞回，仍不能作为真实顾客事件，见 35 文档。多边形、布局生效时间、共享历史以及正式路径和聚合仍未完成。

验证：Node 布局测试覆盖修订、增删、唯一性、跨场景和错误坐标；Edge 无头浏览器检查旧数据迁移、区域/点位增删、无效导入保留原数据，以及实际导出、修改、重新导入。Python 与已有区域测试见本轮验证输出。
