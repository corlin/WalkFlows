# 参考路径区域滞回

2026-11-08：本地回放选中布局区域或点位后，参考路径事件使用可调整的边界缓冲和连续确认时间。默认边界缓冲 0.1 个场景坐标单位、确认时间 0.2 秒，最大相邻样本间隔 0.1 秒；这些是研究演示参数，未经定位精度标定，不能直接用于业务决策。

点在边界缓冲带内时不确认内外状态，并中止待确认的候选；此前已确认状态保留为历史证据。离开缓冲带后，需在同一侧连续达到确认时间才生成进入或离开候选。首段或缺口后首次确认在区域内，进入时间标记未知；缺帧或时间间隔超限时重置状态，禁止跨缺口生成进出。事件在确认帧显示，并记录候选起始帧；该区间是算法证据，不保证涵盖真实物理穿越时间。原始几何候选函数保留供对照。

Node 测试覆盖抖动、短暂穿越、边界带、缺帧、时间间隔及非法参数。使用实际参考轨迹在 Edge 无头浏览器检查了候选、跳帧和阈值切换。结果只适用于数据集参考轨迹及所选矩形，不能视为顾客轨迹、可靠计数或完整 W07；尚需多区域正式事件、真实轨迹质量门禁和评估。
