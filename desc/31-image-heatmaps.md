# 单摄像头观测热图

2026-11-08：本地研究回放新增两路图像空间热图。构建入口仍为 `.venv/bin/python scripts/build_local_review.py`。底图取视频左眼首帧，汇总范围覆盖各自完整的 218 帧；取检测框底边中心为位置，划分 16×12 网格。

可切换检测观测次数和采样时间估计。后者只累加同一相机内、同一局部 ID 连续两帧都在同一格的 1/15 秒；跨格、缺帧和被筛选的观测不连接。该值是采样估计，不能断定两帧之间实际停留在格内。默认不显示硬排除观测，可切换包含它们；硬排除依据的是实验定位与重复候选质量门禁，并不必然表示图像检测错误。两个相机各自归一化颜色，无法根据颜色直接比较强度。

本次样本摄像头 01 默认纳入 213/227 条观测，累计采样时间估计 13.47 秒；摄像头 02 纳入 144/191 条、8.80 秒。时间可跨局部轨迹累加，并非视频时长或去重人数。检测、遮挡、跟踪断裂和未验证的脚点均会影响结果；无观测不代表无人。正式平面热图、到访人数和跨镜去重仍未完成。

验证：23 项 Python 单元测试、区域几何 Node 测试通过；Edge 无头浏览器检查了两个相机、质量筛选及指标切换，并检查了首帧底图和热图区布局。
