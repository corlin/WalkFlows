# 本地回放与区域事件基础

更新：2026-11-08。仅供本地研究，不代表业务验收。

`python scripts/build_local_review.py` 使用项目现有 `.venv` 构建 `data/processed/local-review`，构建时检查两段视频 SHA256、逐帧覆盖和跟踪与质量记录的对应关系。运行 `.venv/bin/python -m walkflows.review_server --port 8765` 后，可访问 `http://127.0.0.1:8765/`。页面展示两路各自的本地检测框、质量状态、参考平面路径和上游入口区域，可创建多个浏览器本地保存的矩形区域及点位，并查看选中项目的参考路径几何变化；布局支持 JSON 导入导出。时间滑块是按片段帧号对照，不证明摄像头曝光同步；参考路径不是本项目已验证的定位、跨镜身份或真实顾客旅程。布局默认只保存在当前浏览器，支持导出和导入；尚无共享历史、生效时间或正式业务事件。

`walkflows/zone_events.py` 汇总单条已通过调用方资格审查的轨迹：仅累加连续同区域观测间隔；缺帧或超出指定时间阈值时截断两侧；相邻区域变化输出发生时间的上下界。轨迹首尾和缺口相邻段标记为截断。它不负责身份关联、定位/质量验证、区域几何或边界滞回，不能直接充当完整 W07。`scripts/probe_reference_zone.py` 对上游入口区域的参考轨迹运行该基础：218 帧连续，参考点均在入口多边形外，未检测到变化；不能据此推断真实到访人数。

验证：Python 单元测试 20 项通过，浏览器区域几何 Node 测试通过；页面曾用本机 Edge 无头模式验证视频加载、区域保存和跳帧。当前仍需完成可靠地面定位及质量评估、跨摄像头关联、正式区域配置和滞回、热力图/路线/旅程，以及整体验收。
