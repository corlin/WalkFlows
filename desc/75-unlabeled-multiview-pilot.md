# Unlabeled training-site multiview feasibility pilot

Plan fixed 2026-11-09 before observing this segment's results. This exploratory audit uses only the pinned train split's unlabeled/site02_u01_s01. The published metadata declares two calibrated stereo cameras, 687 frames at 15 fps, and no ground truth. It is a 45.8-second retail segment from a site already used for training. It is not an independent validation or test set.

Select clip-relative frames 0, 15, ..., 675 (46 synchronized index pairs). Process left eye only in each stereo frame, in the original sequential decode order. Use the existing pinned YOLO11s-pose weights and existing settings: confidence 0.1, image size 640, person class, ankle threshold 0.5, local containment exclusion 0.9. Compose the published scene and camera transformations and project usable ankle estimates within the calibration hull and scene bounds. For each sampled frame report valid projected observations per camera, the nearest cross-camera spatial distances, and mutually unique candidate pairs within 0.5 scene units. Retain source, model and code hashes plus per-frame coverage; fail on missing, mismatched or checksum-invalid input.

The dataset claims synchronization; this diagnostic does not independently establish physical exposure synchronization. No reference identity, camera visibility, false-positive labels or true cross-camera matches are available. A close pair can be two different people and a far or absent pair can reflect occlusion, projection error or incomplete detection. The 0.5 gate is a previously used research setting, not a validated association threshold. Do not train on these candidates or claim tracking accuracy or real counts based only on agreement. Results determine whether a more defensible use of the unlabeled data warrants investigation.
