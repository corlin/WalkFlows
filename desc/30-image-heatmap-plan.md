# 图像坐标观测热图实施计划

目标：在已有双路本地回放中提供真实检测结果的图像空间热图，支持追溯和明确局限。依据 `desc/01-product.md`、`desc/02-architecture.md` 和 `desc/29-local-review.md`。

采用每摄像头独立的检测框底部中心点网格。两个图层分别为检测观测帧数及相邻帧同一局部轨迹、同一网格的可观察时间下界；后者不跨缺帧累加，不假定跨格移动的时间分配。它们是图像空间研究指标，不是去重人数、完整路线或平面定位。保留硬排除观测，但单独过滤，避免数据消失；默认仅研究候选。复用现有离线数据与 `.venv`。

1. 测试并实现网格聚合：空数据、边界、缺帧、重复键和质量过滤；同一轨迹连续帧可贡献时间，不在格网外外推。
2. 构建时将每摄像头结果与输入关联，写入回放数据；对样本数进行守恒检查。
3. 前端展示两种图层及图例和局限，检查两路实际数据及切换行为。
4. 更新状态文档并运行项目测试和本地回放检查。
