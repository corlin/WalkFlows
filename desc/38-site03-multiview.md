# site03 六视角参考对照和跨镜候选

2026-11-08。为避免只围绕单人短片验证，从 [PRCV Labs 公开数据集](https://huggingface.co/datasets/prcvlabs/multiview-retail-tracking) 固定修订 `6cf0e1066653f7efe1d0aae5c49860b19ef9a6e5` 获取 `006_site03_tracks` 的六路视频与已有参考，采用非商业研究许可。视频逐个核验发布的 LFS SHA-256，其他文件及对应上游标定 JSON 核验 Git blob ID。下载过程采用续传和重试；只使用现有 `.venv`，未新增视频标注或训练。

样本包含六路各 400 帧、15 fps 视频，已有参考覆盖 399 帧；最后一帧按参考未知处理。参考文件有 13 个轨迹对象：9 个空、3 个长度分别为 399、355、295 的轨迹，另有一个单帧轨迹；共 1050 个参考点、355 帧有多个参考点。这些轨迹不应直接解释为 13 位顾客。原始 annotation-data 的 1050 个 (轨迹 ID、帧、网格坐标) 与 ground-truth 中的点逐项一致；这只核对文件内部一致性，不证明标注与视频画面的身份或物理精度。场景文件名是 `site03_scene03`，文件内 scene-key 带 `_v1`，相机资源与 manifest 中六个精确版本一致。

六路各 400 帧运行固定的 YOLO11n/ByteTrack 基线，分别得到 50、0、159、0、307、412 条局部跟踪观测，共 928 条；无输出不代表无人。生成图像框底实验投影，保留标定域、前向射线、场景范围与局部高包含框重复候选的排除。C0001029 的 159 条观测中，141 条在标定有效域外，仅 18 条进入几何候选；不能将有效域外结果混入正式分析。

在相同片段帧号对齐和上游参考坐标格式的条件假设下，对每台相机逐帧做一对一距离匹配。半径 0.25 / 0.5 / 1.0 时，C0001055 的 285 条可比较观测分别有 5 / 246 / 280 条找到参考近邻；C0001056 的 383 条分别有 53 / 278 / 379 条。距离阈值是探索参数，不是精度合格线。参考未提供每台摄像头逐帧可见性，未匹配参考不等于漏检，匹配比例不等于精确率、召回率或身份准确率。

跨镜候选独立使用两路预测点构图：双方均只有一个半径内候选时保留，局部轨迹对仅标记观测支持量，不构建全局身份。C0001055 与 C0001056 在半径 0.5 时只有 1 个帧级候选，半径 1.0 时有 233 个；后者 159 个在各自 0.5 的参考近邻对照中指向同一参考点，另外 74 个参考近邻不足。该近邻对照本身依赖实验投影，存在选择偏差，不能当作独立身份真值或匹配正确率。在上述 159 对条件样本中，两路投影距离中位数约 0.655 场景坐标单位；这支持继续调查视角定位偏差，不支持用这批参考直接拟合后宣称准确或盲目扩大融合半径。

## 运行与复核

- 下载及校验：`.venv/bin/python scripts/fetch_site03_sample.py` 和 `.venv/bin/python scripts/fetch_site03_calibration.py`。
- 完整本地研究链：`.venv/bin/python scripts/verify_site03_research.py`；已有输入和模型时不下载或训练，记录运行日志与哈希。该验证只证明计算链执行和数据契约，不证明物理定位、跨镜身份或业务指标达标。
- 本地浏览：`.venv/bin/python -m walkflows.review_server --port 8767 --directory data/processed/site03-review`，访问 `http://127.0.0.1:8767/`。页面可选两路相机、定位帧、查看参考点、实验投影和不同半径候选；视频定位时不提前绘框。
- 产物：`data/processed/site03-reference-eval/` 为逐帧参考近邻，`data/processed/site03-crossview/` 为候选对及支持量，`data/processed/site03-verification/report.json` 为链路验证结果。

浏览器实测第 120 帧在 1.0 半径下显示 C0001055 ID 4 与 C0001056 ID 9 候选，切换到 0.25 后不显示；第 399 帧明确显示参考缺失。当前仍需更强的空间定位验证、遮挡处理、可见性口径、身份关联与最终产品分析，不能据此宣布 W05/W06/W07/W08 完成。
