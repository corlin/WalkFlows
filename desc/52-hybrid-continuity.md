# Fixed-association hybrid continuity comparison

The existing pose-only association membership is held fixed. For each member, the experiment substitutes the already-generated pose-first/box-fallback observations and groups them by frame; it creates no new cross-camera edges. All valid source observations belonging to the fixed members are conserved exactly once. Missing positions stay missing and no interpolation is performed. On the current sample, 549 pose and 197 box-fallback source observations contribute.

The pose-only result has 381 valid hypothesis-frame points, one spatial conflict and 343 adjacent valid frame pairs. Strict mixed fusion has 462 valid points, 42 conflicts and 434 adjacent pairs. Reference-proxy matching at radius 0.5 found 120 matches, 76 no-candidate cases and one missing reference among fallback sources; the corresponding pose-source counts were 541 matches and eight no-candidate cases. These are conditional counts, not independent accuracy, recall or comparable unbiased groups. Conflict resets are excluded from the between-valid-gap tally, so that tally cannot be compared as total missingness.

A separate experimental variant resolves a mixed pose/box conflict by retaining a single pose point only when exactly one pose and at least one fallback source exist. It preserves all source points, marks `mixed_source_conflict`, records selected sources, and does not fuse conflicting fallback positions. It yields 483 valid hypothesis-frame points, 21 unresolved conflicts, 21 explicitly degraded mixed conflicts and 460 adjacent valid pairs. Choosing pose is a research policy, not proof that pose is correct. Two pose conflicts, multiple poses and other disagreements still remain unresolved. Neither variant changes the default page or strict quality gate.

For illustrative north/south and east/west rectangle pairs, the conservative transition detector found zero candidates for all three methods; no business inference follows. Reproduce with `.venv/bin/python scripts/evaluate_site03_hybrid_continuity.py` after the normal fixed-sample pipeline, or run the full verifier. The detailed alternate hypothesis files, summary, source methods, conflicts and hashes are under `data/processed/site03-hybrid-continuity/`. Tests check fixed membership, retained sources, conflict handling, explicit degraded provenance and duplicate keys. The result motivates independent position/visibility validation before a fallback route can become a default.
