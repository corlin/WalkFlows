# Exploratory gap appearance guard

A research-only guard evaluates the relaxed ByteTrack output from document 46. For each local track it extracts a 12-by-8 hue/saturation histogram from the central upper-body box region on the left-eye image. At gaps of one or more unobserved frames it compares the last and next available histogram using Bhattacharyya distance. Above 0.6, or if appearance is unavailable, the output starts a new segment; otherwise it keeps the same segment. Consecutive-frame transitions are untouched. Every input observation retains its frame and original local ID; no frame is interpolated. Input videos and track CSVs are hash checked.

In the same two cameras used to pick this threshold, all 308 and 422 observations were retained. The guard split relaxed C0001056 ID 3 between frames 67 and 83 (distance 0.859), separating the two visually different people documented in 46. It retained the ID 5 gap from frame 169 to 174 (distance 0.38), the candidate that connected baseline IDs 9 and 14. Under the existing conditional reference proximity proxy and mutually unique same-frame box correspondence, ID 3's two resulting segments have support for different reference IDs; ID 5 retains support for reference ID 0. These are selected examples, not a measured identity error rate.

Color is affected by occlusion, clothing similarity, light, bounding-box errors and pose; a low distance does not establish identity, while a high one can split the same person. This method cannot catch consecutive-frame switches. The threshold was selected on these very observations, so it must be checked on independent sequences before it can inform default tracking or metrics. The baseline output and UI remain unchanged.

Reproduce after the experiment in 46 with `.venv/bin/python scripts/experiment_site03_gap_guard.py`. Detailed segment assignments, conflict frames, proxy counts, limitations and input hashes are saved in `data/processed/site03-byte095-experiment/gap-guard.json`. Tests cover gap-only splitting, unavailable appearance and malformed or out-of-order inputs.
