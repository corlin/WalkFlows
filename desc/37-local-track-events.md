# 单摄像头轨迹区域研究与回放定位

2026-11-08：本地回放现在可以选择相机局部 ID 和布局项目，在严格门禁与显式研究门禁下查看区域候选，并将该轨迹的全部输入观测、逐项质量原因、布局版本、参数及结果导出为 JSON。研究模式不放过几何域无效、重复候选等硬排除；它允许尚未验收的投影、脚点和同步证据，因此结果仅作算法研究，不是顾客数量、已验证位置或正式事件。跨镜头不合并身份。

对当前 site02 输入逐条重新核对质量状态与原因：10 条相机局部轨迹共 418 条观测，严格门禁纳入 0 条，研究门禁纳入 357 条；其余 61 条硬排除。使用示例矩形和默认滞回参数产生 18 个带缺口的轨迹事件或状态记录；这是参数化实验结果，不能作人数或真实流转统计。过滤掉的观测和检测缺口不会拼接为连续状态。

回放服务改用 `.venv/bin/python -m walkflows.review_server --port 8765`。它只监听 127.0.0.1，支持浏览器请求视频字节范围；原先 `python -m http.server` 不支持该片段的 Range 定位。滑块切换时先清除旧框，等待对应视频定位完成再绘制该帧检测框；连续播放等待两路定位后推进，解码较慢时回放速度可能低于原始帧率。此机制只保证浏览器画面与所请求帧的呈现顺序，不证明双摄曝光同步或物理坐标准确。

验证：单元测试覆盖严格/研究门禁、相机 ID 隔离、质量状态冲突、缺口、JSON 来源与副本；真实样本集成检查 418 条记录。HTTP 测试检查完整读取、指定范围、后缀范围、HEAD 和 416。Edge 实际录像测试验证定位期间不绘框、定位完成后绘框、播放继续推进；页面测试验证严格/研究切换、事件跳转及 JSON 导出。
