## 目标与默认前提

用户确认首版用于内部研究和原型验证，处理公开的离线录像，验证从视频到空间触点和客户旅程的链路。不采集新数据、不自行标注、不训练模型。具体数据和组件仍须核验许可；对外演示或商业交付前需重新核对授权。

当前工作机为 Apple M1 Pro、16 GB 内存，2026-11-06 观察到约 80 GiB 可用磁盘；数值随时间变化。默认串行或低并发处理短片段，优先试 MPS，失败回退 CPU。下载前检查实际文件大小和剩余空间；不下载 SmartSpaces 全库。

用户补充：尽量在本机验证；仅当内存、运行时间或兼容性确实成为瓶颈时，考虑使用配备双 5060 Ti、48 GB 内存的 PC。双卡显存容量及环境尚未确认，不假设可以合并显存。

用户要求 Python 运行时、虚拟环境和依赖使用 uv 管理；项目应使用 `pyproject.toml` 与锁文件固定可复现环境，不依赖当前损坏的默认 Python。具体 Python 版本由组件兼容性及本机验证决定。

用户进一步明确：不追逐 Ultralytics 最新版，也不限定供应商，优先选择可靠、可用的开源 YOLO。当前固定版 YOLO11 仅用于基线；[YOLOX 对照](07-baseline-results.md)和权重许可验证完成前不确定最终方案。

用户要求主要演示样本优先真实门店且画面清晰；CITIC Showroom 仅作技术验证。已下载 PRCV Labs 的少量真实门店候选，其双目格式、标定和许可边界见 [视频筛选](10-retail-video-selection.md)。

用户指出：实施前应充分参考此前提出的开源项目。暂停把当前实验视作最终架构或模型选型，先形成可核查的项目对比和复用方案。

已补充四个项目的固定版本源码静态核查，结论见 [开源项目核查](08-open-source-review.md)。其中 MelMOT 的 BoT-SORT 和外观比较存在占位实现。此后已在独立 uv 环境运行两个项目的部分组件测试，范围和新增候选见 [上游验证](09-upstream-validation.md)；端到端复用方案仍待验证。

## 方案比较

| 路线 | 优点 | 代价 | 建议 |
| --- | --- | --- | --- |
| CITIC 真实室内片段 + 本地离线处理 | 有平面图、标定、同步信息，先验证真实视频链路 | 展示厅不是实际零售店；非商业许可；参考位置由离散路点生成，需先确认可用精度和覆盖 | 首选内部研究基线 |
| SmartSpaces 零售子集 + 本地离线处理 | 更接近零售布局，具备跨摄像头及空间标注 | 需选具体场景、确认下载大小与格式；合成场景效果不能代表真实门店 | 第二套验证及许可替代候选 |
| 直接对接真实门店 | 最贴近最终使用 | 需要采集、授权与现场条件，违背当前约束 | 不作为本期方案 |

## 默认技术选择

1. **输入**：先查 CITIC 归档文件清单，优先选择一组包含入口及展示厅连接路径的同步数据；若无法部分下载则先核对完整包体积和空间。Showroom 为单台摄像头，要验证重叠去重另选 HallWide / HallSeg；跨区域连接先检查实际覆盖与同步。
2. **检测与单摄像头跟踪**：Ultralytics 官方预训练轻量模型 + 明确指定 ByteTrack；选择具体稳定版本和权重需经环境试运行后记录，不能预先宣称某版最稳定。必要时比较 BoT-SORT，固定版本及校验值。
3. **多摄像头**：按数据集的同步和标定投影至公共地面；先按时空和覆盖拓扑保守关联，重叠视野需同一时刻去重；使用置信度和未关联状态。预训练 ReID 是需要时才加入的候选，不保证外观相似即可正确匹配。
4. **语义与界面**：先用本地配置定义区域/点位，并采用 Python 离线处理与本地 Web 可视化；持久化中间轨迹和事件，以便回放和复算。具体 UI 框架和存储格式在环境验证时确定。
5. **ScreenFlows 对接**：第一版复用概念与事件契约，不直接复制或绑定其引擎；确认其接口、数据格式及许可后再决定代码或接口复用。现有空间旅程可以先独立导出。
6. **真实与模拟**：入口、区域与停留来自视频推断；咨询和成交若需要演示则由独立模拟数据提供，并在页面及导出显著标记。

## 验证门槛

- 样本准入：能读录像、时间同步和标定，且至少两个摄像头存在可验证的空间或时间连接；记录选择的摄像头及时间范围。
- 可复现：同一输入、固定版本和配置能生成可追溯的观测、轨迹、关联和区域事件；保留算法版本与来源。
- 质量：依据现有参考数据支持程度分别测人数、地面位置、轨迹关联和区域事件；标明对齐方式、样本量、覆盖率、误差、未知及不可评估项。CITIC 路点参考可能稀疏或插值，不能假设提供逐帧检测框真值或精确的区域进出时间。
- 回放：叠加展示摄像头、地面轨迹、置信度和中断；无法匹配时保留断点，不能伪造连续轨迹。
- 性能：记录硬件、片段时长、帧率、处理耗时、峰值内存及磁盘；离线运行不承诺实时。阈值在看到基线与实际用途后决定。
