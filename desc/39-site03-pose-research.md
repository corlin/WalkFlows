# site03 姿态脚点与区域研究

2026-11-08。针对六路视频中已有局部跟踪的帧，用固定哈希的预训练 YOLO11n-pose 提取姿态。姿态框与跟踪框按同帧 IoU ≥ 0.5 做双向唯一候选匹配；多候选或无候选不强行指派。只在已有轨迹的帧运行姿态推理，因此不能用这些结果评估画面级姿态召回。[Ultralytics 结果接口](https://docs.ultralytics.com/reference/engine/results)提供关键点坐标和可选分数；分数不是本样本上经校准的可见性概率。

实验脚点规则：脚踝分数至少 0.5；两侧均满足时取中点，仅一侧满足时使用该侧。空点、低分、框匹配歧义、图像外坐标保持未知。对脚点重新检查该点对应的标定有效域、射线和场景范围，并排除局部高包含框重复候选；该方法的有效域检查依据脚点本身，而不是继承框底点的位置状态。所有输出仍是研究候选，不解除物理定位、脚点可见性、同步或跨镜身份的严格门禁。928 条局部观测中，六台相机分别有 14、0、8、0、201、326 条脚点研究候选；没有候选不代表无人。

## 条件对照与取舍

在 C0001055 与 C0001056，两种投影均可用、两路框底投影各自距同一参考点不超过 0.5，且参考近邻和姿态框对应唯一的共同支持集有 122 对帧。框底跨镜距离中位数约 0.658，脚点约 0.213 场景单位；同一支持集内，框底 1/122 对、脚点 122/122 对在 0.5 以内。这些帧仅来自两组局部 ID 对（104 帧与 18 帧），并非 122 个独立顾客；参考对应依赖框底位置，存在截断和选择偏差，不是身份准确率或独立泛化验证。

另一视角 C0001029 在同样参考半径、脚踝分数 0.5 的条件下只有 5 个可配对观测，其中 4 个脚点比框底离参考更远。结果提醒我们不能对全部摄像头一律替换脚点，也不能把姿态分数直接提升为可见性真值。研究性跨镜候选在 C0001055/C0001056、半径 0.5 下，框底法有 1 个帧级候选，脚点法有 175 个；两种方法的观测覆盖不同，该数字不能直接当成性能提升或正确关联数。

## 回放与复现

site03 本地回放可在“检测框底”和“脚踝点”之间切换；脚踝点显示采用上述 0.5 研究阈值。可为该场景配置多个矩形区域/点位并导出或导入布局，选择视角及相机局部 ID 后查看实验区域候选。缺帧和质量排除中断状态；该区域结果不是顾客事件。浏览器实测区域保存、局部轨迹跳帧、两种定位方法切换、布局导出恢复以及跨场景导入拒绝。

- 姿态推理：`.venv/bin/python scripts/probe_site03_pose.py`；已有缓存可用 `scripts/verify_site03_pose_evidence.py` 验证来源和一对一对应。
- 对照与研究候选：`compare_site03_pose_reference.py`、`compare_site03_pose_crossview.py`、`export_site03_pose_floor.py`、`probe_site03_pose_crossview.py`；均由 `scripts/verify_site03_research.py` 在已有姿态缓存时依次运行。
- 查看：`.venv/bin/python -m walkflows.review_server --port 8767 --directory data/processed/site03-review`，访问 `http://127.0.0.1:8767/`。
- 结果位于 `data/processed/site03-pose-comparison/`、`site03-pose-crossview/`、`site03-pose-floor/` 和 `site03-pose-proposals/`；完整链路通过 39 项 Python 测试及 JavaScript 检查。
